# بداية | Bidayah — الموقع

موقع عربي (RTL) لخدمة وساطة سرية بهدف الزواج الشرعي: صفحة رئيسية، واستمارة طلب من ثماني خطوات على المسار `/apply/`، وصفحتا «من نحن» `/about/` و«تواصل معنا» `/contact/`.

React 19 + TypeScript + Vite، وCSS منظم بالـdesign tokens، دون مكتبات حركة أو واجهات إضافية.

## التشغيل

```bash
npm install
npm run dev        # خادم التطوير: http://localhost:5173 و /apply/ و /about/ و /contact/
npm run build      # فحص الأنواع + بناء + توليد HTML الصفحات مسبقًا داخل dist/
npm run preview    # معاينة نسخة البناء
```

مجلد `dist/` موقع ثابت جاهز لأي استضافة. الصفحات تُولّد مسبقًا (`scripts/prerender.mjs`)، فيظهر المحتوى قبل تحميل JavaScript.

### الرفع على Hostinger

ضع بيانات FTP الخاصة بالنطاق في `deploy.settings.ps1` (نسخة من `deploy.settings.example.ps1`، ولا يُرفع ولا يُشارك)، ثم شغّل في PowerShell:

```powershell
.\deploy.ps1              # يبني الموقع ثم يرفع محتوى dist/ المتغيّر فقط
.\deploy.ps1 -SkipBuild   # يرفع dist/ الحالي دون إعادة البناء
.\deploy.ps1 -Force       # يعيد رفع كل الملفات
```

يتذكّر السكربت ما رفعه في `deploy.state.json`، فلا يرفع إلا الملفات التي تغيّر محتواها.

### إضافة سؤال أو تعديله
كل سؤال كائن داخل `steps` في `src/content/apply.ts`. الأنواع المتاحة: `text`، `email`، `tel`، `number`، `textarea`، `select`، `radio`، `checkboxes`، `ageRange`. يحدد `showIf` شرط الظهور، و`requiredIf` الإلزام المشروط، والدالة `otherDetails()` تضيف حقل «أخرى» المرتبط. التحقق والمراجعة وبيانات الإرسال تُبنى تلقائيًا من هذا الملف.

## إرسال الاستمارة ونموذج التواصل

يرسل النموذجان إلى `public/api/send.php`، وهو ملف PHP يعمل على استضافة Hostinger ويُرفع مع الموقع. يحوّل كل طلب أو رسالة إلى بريد عربي مقروء ويرسله إلى بريد الفريق عبر `mail()`، ولا يخزّن أي بيانات على الخادم، فالبريد هو النسخة الوحيدة. لتغيير البريد المستقبِل عدّل `MAIL_TO` في أول الملف.

الربط معرّف في `.env.production`، فيُفعَّل في نسخة البناء فقط. خادم التطوير (`npm run dev`) يبقى في الوضع التجريبي: يعرض بوضوح أن الطلب لم يُرسل ولم يُحفظ، ولا يرسل شيئًا. وكذلك أي نسخة بناء تُحذف منها هذه المتغيرات.

العقد (`src/lib/submit.ts`، المشترك بين النموذجين):

- `POST` بجسم JSON: `{ "formVersion": 1, "answers": { ... }, "summary": [ ... ] }`. تُرسل إجابات الحقول الظاهرة فقط، والمدى العمري بصيغة `{ "min": 30, "max": 38 }`. و`summary` نص الأسئلة والإجابات كما في صفحة المراجعة: `[{ "title": "...", "rows": [{ "label": "...", "value": "..." }] }]`، ومنه تُبنى رسالة البريد.
- `2xx` → تظهر رسالة الاستلام.
- `422` مع `{ "fieldErrors": { "name": "رسالة عربية" } }` → تنتقل الاستمارة إلى الخطوة المعنية وتعرض الرسالة على الحقل.
- `429` / غير ذلك / انقطاع الشبكة → رسالة خطأ عربية، وتبقى الإجابات في الصفحة.

يتحقق الخادم من بنية الطلب وحجمه، ومن الحقول الأساسية فقط (الاسم ووسيلة التواصل والإقرار)، أما بقية الإجابات فتصل كما كُتبت. ويحدد 5 رسائل لكل عنوان IP خلال 10 دقائق.

**نموذج التواصل** في `/contact/` يعمل بالطريقة نفسها وبالعقد نفسه، وله متغيره الخاص (`src/contact/submit.ts`). يرسل `name` و`topic` و`message` و`replyVia` و`email` أو `phone`، ولا يُرسل إلا حقل وسيلة الرد التي اختارها المستخدم.

الخصوصية في الواجهة: حالة الاستمارة ونموذج التواصل في الذاكرة فقط (لا localStorage ولا cookies ولا تحليلات ولا سجلات console)، والخطوط مستضافة ذاتيًا فلا تُرسل أي طلبات إلى جهات خارجية.

## قبل النشر

1. **ملف المحتوى الأصلي لم يصل مع طلب التنفيذ.** النصوص المعلّمة بتعليق «مسودة» في `src/content/*.ts` صيغت من وصف الخدمة، ويجب مطابقتها مع الملف، وتحديدًا:
   - أسئلة الاستمارة واختياراتها (المسودة الحالية 38 سؤالًا، منها حقول شرطية، إضافة إلى الرسالة الإضافية والإقرار و5 حقول «أخرى»؛ بينما يحتوي الملف الأصلي على 33 سؤالًا) والإقرار.
   - أمثلة الدول، ونص المساعدة القانونية، وأوصاف مراحل الرحلة.
2. **سياسة الخصوصية** المعروضة في الخطوة الأخيرة مسودة معلّمة بذلك، وتحتاج مراجعة قانونية وتشغيلية: الجهة المسؤولة، مدة الاحتفاظ، طريقة طلب الحذف، ومكان التخزين.
3. **وسائل التواصل المباشر** (البريد، واتساب، الهاتف) فارغة في `src/content/contact.ts`، فلا يظهر قسمها في صفحة «تواصل معنا» حتى تُملأ. الوسيلة التي تبقى فارغة لا تظهر.
4. **نصوص «من نحن» و«تواصل معنا»** مسودة مبنية على وصف الخدمة في بقية الموقع، ولا تتضمن أي معلومات عن المؤسسين أو تاريخ أو أرقام؛ راجعها واعتمدها، وأضف بيانات الجهة المشغّلة إن لزم. عبارة الخصوصية أسفل نموذج التواصل يجب أن تتوافق مع السياسة المعتمدة.
5. **صورة المشاركة:** `og:image` في الصفحات الأربع يشير إلى `https://bidayatzawaj.com/og.png`؛ حدّثه إن تغيّر النطاق.
6. الرمز البصري أصل قابل للاستبدال، وليس شعارًا تجاريًا معتمدًا.
